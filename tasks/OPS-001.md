# OPS-001 — Install 9Router fresh di CT 300

Akses: `ssh ct300` (user router, TANPA sudo). Node 22 dan pm2 sudah terpasang global. RAM 4 GB.

Kondisi awal: instalasi npm global sebelumnya sudah dihapus, dan /home/router/.9router sudah dikosongkan. File ~/.9router-initial-password berisi password awal dashboard.

Tujuan: 9Router versi terbaru dari source resmi https://github.com/decolua/9router, berjalan headless via pm2.

## Ketentuan
- Clone ke /home/router/9router, checkout tag rilis terbaru (bukan branch main), npm ci, npm run build. Ikuti README versi itu; jika berbeda dari instruksi ini, laporkan perbedaannya.
- .env (chmod 600): PORT=20128, HOSTNAME=0.0.0.0, NEXT_PUBLIC_BASE_URL=http://10.10.10.30:20128, DATA_DIR=/home/router/.9router, INITIAL_PASSWORD diambil dari ~/.9router-initial-password. JANGAN pernah menampilkan isi password atau secret apa pun.
- Jalankan: pm2 start npm --name 9router -- start; pm2 save. Cetak perintah `pm2 startup` yang harus dijalankan root oleh pemilik (jangan coba sudo).
- JANGAN menambahkan provider, akun, atau API key apa pun. JANGAN mengubah apa pun di luar /home/router.
- Jika build gagal karena memori atau alasan lain, BERHENTI dan laporkan outputnya. Jangan mencoba jalur instalasi lain tanpa izin.

## Verifikasi (bukti wajib)
- ssh ct300 'ss -ltnp | grep 20128' → listen di 0.0.0.0:20128
- Dari VM ini: curl ke http://10.10.10.30:20128/ (200/30x) dan /v1/models (401 atau 200)
- pm2 restart 9router, lalu cek ulang: tetap jalan
- Jelaskan cara backup yang aman untuk SQLite (data.sqlite + WAL, misalnya lewat sqlite3 .backup)
