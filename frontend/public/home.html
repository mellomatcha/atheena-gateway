Apa itu ATHEENA?+

ATHEENA adalah pintu masuk untuk mengakses model AI melalui gateway 9Router resmi, dengan portal dan identitas visual kami sendiri. Model yang tersedia mengikuti koneksi provider yang diatur admin.

Apakah semua orang bisa membuat akun?+

Akses dikelola oleh admin. Akun workspace dan API key pribadi punya fungsi berbeda. Pendaftaran mandiri belum tersedia.

Apa bedanya password dan API key?+

Password digunakan untuk masuk ke portal pengelolaan. API key digunakan oleh OpenCode atau aplikasi untuk memanggil model. Jangan membagikan keduanya atau memasukkan API key ke kode frontend publik.

Model apa yang bisa digunakan?+

Lihat daftar terbaru melalui endpoint /v1/models dengan API key yang valid. Contoh integrasi di halaman ini memakai deepseek-v4.1-flash, yang sudah diuji pada gateway ini. Ketersediaan model lain mengikuti provider.
